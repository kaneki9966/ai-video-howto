# 手順書：もしも系3Dシミュレーション動画の作り方

出典動画：ネット動画研究所「最近よく見る『もしも系3D動画』なぜ全部同じなのか？」（https://youtu.be/Kzo0d_aLULQ 、6:40）
字幕テキスト：transcript.txt（同フォルダ）

## ジャンルの型
- 現実ではありえない「もし○○が2秒ごとに2倍になったら」という状況を3Dアニメで再現する
- 冒頭で結果の一部を先に見せてから、シミュレーション開始
- 数秒ごとに状況がエスカレートし、時間・数値を画面に表示
- 終盤は地球規模まで話が大きくなる
- 3Dモデル自体は単純、背景の建物・小物は細かく配置
- 文字は白い明朝体が中心、重要な数字だけ黄色・オレンジで強調

## 制作ツール（動画内の構成）
- Claude：プログラムの作成・実行を担当
- Three.js：3D映像
- Remotion：動画の書き出し
- 人間の担当は「企画の指定」「生成動画の確認」「不自然な部分の指摘」だけ

## 手順
1. Claudeに「もしも系3Dアニメを作りたい」と頼み、生成用プロンプトを作らせる→そのまま実行させる
2. 有名動画を分析して特徴を取り入れる：
   - 主人公に物語がある
   - 周囲の人間が状況に反応する（音が大きくなれば耳を塞ぐ等）
   - 衝撃でカメラが揺れる、複数カメラの切り替え
   - 終盤に地球規模へエスカレートするオチ
3. 生成→目視確認→不具合（貫通、足が動いていない等）を指摘→修正、を繰り返す
4. BGM・効果音を追加
5. 制作過程と修正履歴をClaudeに分析させ、人物モデル・カメラワーク・効果音などを再利用できる「テンプレート」にまとめる
6. 次回からはテンプレートで生成し、発生した問題と修正方法をテンプレートに追記していく

## 効果（動画内の実測）
- 1本目（掃除機）：約131分
- 2本目（回転寿司、テンプレート使用）：約46分
- 3本目（バスケットボール、問題集を追記）：約33分
- テンプレートと修正経験の使い回しで大幅に短縮できる
