# Text Animators in After Effects（School of Motion）
- URL: https://www.youtube.com/watch?v=b1_p2qQf_Ts
- テーマ: テキストアニメーター（アニメーターの積み重ね／セレクタ活用）

## 技法と手順

### 基本構造（全技法共通の考え方）
- テキストレイヤーの「アニメート」ボタンから、変更したいプロパティ（Position、Scale、Rotation、Opacity、Anchor Point 等）を選んでアニメーターを追加する
- アニメーターは「プロパティの変更値」と「レンジセレクタ」の2部分で構成される。レンジセレクタの Start 0%〜End 100% が文字列全体への影響範囲を示し、Start／End／Offset をアニメーションすることで文字ごとに順に影響を伝播させる
- 基準（Based On）は Characters / Words / Lines に切り替えられる
- デフォルト設定のままでは文字が1つずつ硬く動き、重なりもイージングもないため、Advanced の設定調整が前提になる
- 手法の核は「アニメーターを1つで完結させず、複数に分けて積み重ねる」こと。最初のアニメーターは初期状態（初期位置・アンカーポイント等）の設定専用とし、アニメーションさせない使い方をする
- 作ったアニメーションは、テキスト内容を打ち替えるだけでそのまま使える（長い単語や文でも、キーフレーム間隔を広げるだけで対応できる）

### バウンス（Bounce：飛び上がって overshoot して着地）
- Position アニメーターを追加し「Initial Position」とリネームする。文字全体を下へ下げた初期位置を設定する（このアニメーター自体はアニメーションしない）
- Ctrl/Cmd+D 相当の操作で複製し「Position 01」とする。値は相対値である点に注意する。初期位置から行き過ぎる位置まで戻すため、動画では -663 よりさらに小さい値が使われる
- Position 01 のレンジセレクタで Offset をアニメーションする：-100 にキーフレーム → 1秒地点で進める（Shape 変更後は最終的に 100 まで必要）
- Advanced の Shape を Square から Ramp Down に変えると、文字同士の動きに重なり（オーバーラップ）が生まれる
- Ease High を 100 に上げると最終位置へのイーズインになる。字幕内では「Ease High＝イーズイン、Ease Low＝イーズアウト」と整理される。このバウンスでは Ease Low は 0 のままにし、初期位置からは勢いよく出て、最終位置へイーズインさせる
- さらに複製して「Position 02」を作り、Position を 0 にリセットしてから Y を少し下げ、キーフレームを約2フレーム後ろへずらす。これで着地前の overshoot（行き過ぎて戻る動き）になる
- Position 02 では Ease High と Ease Low の両方を効かせたいが、両方 100% にするとイージングが崩れる場合があるため、両方 50% にするときれいに収まると説明される
- 同じ要領で逆方向（例：-45）への複製を重ねると、反対側への小さな跳ね返しも追加できる。ただし積み重ねすぎると動きが弱まるため、キーフレーム間隔を広げる調整が必要になる

### グリッチ（Glitch：Wiggly セレクタでランダムに伸縮・移動）
- 最初に Anchor Point のアニメーターを追加し「Anchor Point Fix」とリネームして、アンカーポイントを文字の中央へ移す（デフォルトは文字の下端）。以降のアニメーターはすべてこの新しいアンカーポイントを使う
- Scale のアニメーターを追加する
- セレクタを追加できる点が要点で、通常のレンジセレクタの代わりに／加えて Wiggly セレクタを追加すると、順番ではなくランダムに文字が選ばれる
- セレクタの Mode の違い：Intersection は既に選択されている範囲内だけに作用する、Add は既存の選択にランダム選択を加える、と説明される
- Wiggly セレクタの Wiggles Per Second を 0 にして、時間で勝手に動かないようにする
- Dimensions をロック（字幕では「lock the dimensions」）すると X と Y が同率でスケールし、文字が歪まない
- Scale は 200〜250 程度に設定する。選択率 100% の文字はその値に、50% の文字はその中間値になる仕組みが説明される
- Wiggly の Max Amount 100% / Min Amount -100% のままだと負の選択率で文字が縮小もする。縮小させたくない場合は Min Amount を 0 にする（動画ではあえて -100 に戻して縮小も混ぜている）
- レンジセレクタは 100% に戻して全体を選択対象にする
- Random Seed を変えるとランダムパターンが滑らかに変化する。これを利用し、Random Seed にキーフレームを打ち、Cmd/Ctrl+Option+クリックでホールドキーフレームにして、数フレームごとに Seed を変えて「数回ツイッチ（痙攣）して止まる」動きを作る
- 収束させるには、レンジセレクタの Start を 100 へアニメーションする。Start 100%／End 100% で何も選択されず、Intersection の Wiggly は作用しなくなる。これに Easy Ease をかける
- 同じアニメーターを複製し「Wiggly Position」として、Scale プロパティを削除して代わりに Position（Y）プロパティを追加すれば、位置のツイッチをスケールと別タイミングでずらして制御できる

### スライド（Slide：Per-character 3D で奥から回転しながら出現）
- 「Enable Per-Character 3D」を有効にすると、各文字を3Dオブジェクトとして扱え、Position／Scale／Rotation が X・Y・Z を持つ
- 初期設定用アニメーターで Anchor Point を文字中央に置き、さらに Z 方向へ後ろ（動画では分かりやすく 200 ピクセル）に置く。以降の回転はこのアンカーポイントを支点に起こる
- Rotation の初期設定用アニメーターで初期回転（動画では Y Rotation -142.5）を設定する（アニメーションしない）
- 複製して「Rotation 01」とし、Y Rotation を +142.5 にして相対的に元の向きへ戻す
- レンジセレクタの Advanced で Shape を Ramp Down、Ease High 50 / Ease Low 50 にし、Offset を -100 →（1秒で）100 へアニメーションする
- Opacity 用にも複製を作り Rotation プロパティを削除する。初期設定側に Opacity 0% のプロパティを追加し、Opacity 用アニメーター側は Opacity 100% にする。既に Offset キーフレームがあるため、回転しながらフェードインする
- キーフレームを少しずらすと出現タイミングを遅らせられる
- 仕上げとして Z Rotation を加え、傾きながら入る動きも同じ考え方で足せる

### オルタネート（Alternate：Expression セレクタで奇数・偶数を逆方向へ）
- Position アニメーターに Expression セレクタを追加する。「Amount」のエクスプレッション内で使える変数として selectorValue、textIndex（何番目の文字か）、textTotal（総文字数）が紹介される
- 偶数／奇数の判定には剰余演算子 % を使う：`textIndex % 2 == 0` は「2で割った余りが0＝偶数番目の文字」という判定になる（比較には `==` を使う）
- 字幕で示されるエクスプレッションの形：
  - `if ((textIndex % 2) == 0) { selectorValue } else { -selectorValue }`
  - 偶数文字は通常の選択値、奇数文字は負の選択値になるため、奇数文字だけ Position の作用方向が反転し、上下交互に動くスロットマシン風の動きになる
- 初期値用アニメーター（例：Position 100）を複製して「Position 01」とし、-100 にして元の位置へ戻す。Advanced は Ramp Down、Ease High 100% にし、Offset を1秒かけてアニメーションする。振幅を大きくする例では初期値 300 / 戻し -300 が使われる
- Opacity は Expression セレクタ付きのアニメーター内では正しく 0 にできない（負の選択値×0 の問題）ため、別アニメーターとして分ける：「Initial Opacity」で Opacity 0、複製した「Opacity Change」で Expression セレクタを削除し Opacity 100% にする

## 見た目の特徴
- バウンス：文字が下から1文字ずつ重なりながら飛び上がり、行き過ぎてから小さく跳ね返って着地する
- グリッチ：ランダムな文字だけが拡大・縮小と上下移動を数回ツイッチし、やがて通常の文字列に収まる
- スライド：文字が奥の支点を中心に回転しながら横から滑り込み、同時にフェードインする
- オルタネート：奇数文字と偶数文字が上下逆方向から交互に滑り込んで揃う
- いずれもモーションブラーが効くと説明される

## デザイン上の注意点
- 標準プリセットの見た目は「チープ／canned」に見えがちだが、自作すればカスタムに見える、というのが動画全体の主張
- アニメーターを役割ごとに分割（初期設定用／動き用、Scale 用／Position 用、Opacity 用）すると、後からタイミングをずらしたり量を調整したりしやすい
- Ease High と Ease Low を両方 100% にするとイージングがおかしくなる場合があり、50% ずつが落としどころとして示される
- 積み重ねすぎると動きが相殺されて弱まるため、キーフレーム間隔の調整が必要
- 多数のタイトルを扱う案件では、打ち替えだけで使い回せることが最大の時短になると強調される
