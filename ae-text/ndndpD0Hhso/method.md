# Bevel Depth Effect in After Effects - 3D Depth / Engrave Effect（Motion Nations）
- URL: https://www.youtube.com/watch?v=ndndpD0Hhso
- テーマ: 3Dベベル／奥行き（レイヤースタイルによる彫り込み風）

## 技法と手順

### セットアップと背景
- 新規コンポジション「main」：1920×1080、30fps
- Solid を新規作成し、Gradient Ramp エフェクトを適用する
- 開始色・終了色（動画では終了色を青系）を設定し、グラデーションの開始点・終了点を動かして配置する。色は自由に選んでよいとされる

### シェイプの作成
- Shape ツールから Polygon（Polystar）ツールを選んでドラッグし、シェイプを作る
- Fill は None にし、Stroke を少し加える
- Align パネル（Window から表示）でコンポジション中央に揃える
- Ctrl を押しながらアンカーポイント用アイコンをダブルクリックし、アンカーポイントを中央にする
- Polystar の Points 数を変えることで形を変えられる：4で四角、大きく増やすと円になる

### レイヤースタイル1：Inner Shadow（奥行きの本体）
- レイヤーを右クリック → Layer Style > Inner Shadow を適用する
- Distance を調整し、Size をかなり大きくする
- Angle を 50〜60°程度に設定する（光の方向は好みで調整）
- このままだと白い色が見えるため、レイヤーの描画モードを Multiply に変更すると消えて、きれいな奥行き表現になる

### レイヤースタイル2：Bevel and Emboss（縁のハイライト）
- 同様に Layer Style > Bevel and Emboss を有効にする
- Size を大きくしすぎると偽物っぽくなるため、7 程度に抑えて縁のハイライトを出す
- Angle は 120 に設定する
- Altitude を下げると暗い部分が消え、ハイライト部分だけが残る
- Highlight の色を背景に合わせた青系のトーンにし、Opacity は好みで増減する

### 質感と仕上げ（シェイプ側）
- Inner Shadow に Noise を 1〜2 程度だけ加える（やりすぎない）
- Stroke を太くすると見た目が変わる。シェイプレイヤーなので自由に変形・アニメーションできる
- レイヤーの Opacity（T キー）を 70 程度に下げるとより馴染むとされる

### テキストへの適用
- テキストツールで文字（例：「hello」）を入力し、大きくして中央に揃える
- テキストを右クリック → Create > Create Shapes from Text でシェイプレイヤー化する（この変換が必須）
- 元のシェイプ側のレイヤースタイル2つ（Inner Shadow と Bevel and Emboss）を選択して Ctrl+C でコピーし、テキストのシェイプレイヤーへ Ctrl+V で貼り付ける
- 描画モードを Multiply に変更する
- テキスト用に Inner Shadow の Distance と Size を小さめに再調整し、Angle や縁ハイライトの強さ・色も好みで直す

### アニメーション例
- Scale にキーフレームを打ってスケールアニメーションを付ける
- Stroke Width にもキーフレームを打ち、開始時点を 0 にする
- キーフレームを選択して F9 をかけ、グラフエディタでカーブ形状を調整する
- キーフレーム同士を近づけると動きが速くなる

## 見た目の特徴
- 平面のシェイプ／文字が、内側の影と縁のハイライトによって彫り込まれたような（エングレーブ風の）立体的な奥行きを持つ見た目になる
- 背景のグラデーションと同系色のハイライトで、面に光が当たっているような表現になる

## デザイン上の注意点
- Bevel and Emboss の Size の上げすぎは「偽物っぽい」見た目になるため小さめ（7程度）にする
- Inner Shadow の Noise も 1〜2 に抑え、やりすぎない
- 白い縁が見える問題は描画モードを Multiply にすることで解消する
- 角度・色・不透明度はすべて好みで調整してよいと繰り返し語られている
