# 文字の書き順アニメーション
- URL: https://www.youtube.com/watch?v=EdngHxTplqo
- テーマ: 書き順／手書き風アニメーション

## 技法と手順

### 全体の流れ
- 1. テキストを配置する
- 2. 書き順通りにパスを配置する
- 3. エフェクト「線」を適用する
- 4. はみ出す部分にマスクをかける

### テキスト配置とパス作成
- テキストはAE上で作っても、Illustratorで作っても、画像でも構わない
- テキストを配置したレイヤーを選択し、ペンツールを選択する
- 書き順通りに左から右へ、一画ごとにパスを打つ
- 毛筆や筆記体の場合、一画を複数のパスに分けるとマスクがかけやすくなる
- 2本目のパスを打つ前に、必ず1本目のパスを確定する。確定しないと1本目の続きとしてポイントが延長されてしまう
- パスの確定は、別のレイヤーを選択して再度テキストレイヤーを選択してもよいが、画面内の空いている場所で Option+クリックする方法が紹介されている
- パスはなるべく線の中央に打つ。後から位置の微調整、ポイントの追加・削除ができるので、最初はざっくり打てばよい

### エフェクト「線」の適用
- テキストレイヤーにエフェクトの「線」を適用する
- 「全てのマスク」にチェックを入れる
- 色は何色でもよい（動画では分かりやすく赤に設定）
- ブラシの硬さは100%
- ブラシのサイズは、テキストが赤い線で隠れるまで上げる
- ペイントスタイルを「元のイメージを表示」に変更する（赤い線が一旦消える）

### アニメーション設定
- エフェクト「線」を展開し、「終了」にキーフレームを打つ
- 例として、1フレーム目を0%、20フレーム目を100%にする
- この尺は書き始めから書き終わり全体の尺ではなく、一画分の尺を指定する。尺は好みでよい

### はみ出しを消すためのレイヤー複製とマスク割り当て
- 再生するとはみ出している部分が多々見受けられるため、マスクで消していく
- その前に「線」の設定で「全てのマスク」のチェックを外す。するとパスがマスク1のみとなり、そのレイヤーでは最初に作ったパスのみ再生される
- マスクの数だけレイヤーを複製する。動画の例ではマスクが17枚なので、レイヤーを16枚複製する
- 各レイヤーに下から順にマスク2、マスク3…と割り当てる
- キーフレームで設定した間隔で、各レイヤーのタイミングをずらす

### はみ出し部分へのマスク処理
- 最初のレイヤーから順にマスクを設定する
- 線が全て見えている状態にして、新規マスクを作成する
- ペンツールを選択し、はみ出す部分を覆うようにマスクを調整する
- 次のパス、3つ目のパスも同様に、はみ出す箇所をマスクする
- マスクの必要がないパスもある（動画では4つ目のパスは不要と判断）
- 全てのパスに対して同様のマスク処理を行う

### 描画速度の調整
- 最後に、パスの描画速度が全て均等な状態から調整する
- 描画スピードを早めたり遅めたり、タイミングを早めたり遅めたり、間を取ったりする

## 見た目の特徴
- テキストが書き順通りに一画ずつ描かれていくように表示される
- 調整前は各画の描画速度が均等で、はみ出し部分が見える状態になる

## デザイン上の注意点
- 一画を複数のパスに分けておくとマスクがかけやすくなる
- パスは後から微調整できるので、最初は線の中央を意識しつつざっくり打つ
- アニメーションの尺は全体ではなく一画分で指定すること
