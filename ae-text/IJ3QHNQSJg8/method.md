# Text Animators for Beginners - After Effects Type Tutorial（Motion by Nick）
- URL: https://www.youtube.com/watch?v=IJ3QHNQSJg8
- テーマ: テキストアニメーター入門

## 技法と手順

### ソーステキストへのキーフレーム
- テキストのドロップダウンを開き、「ソーステキスト」にキーフレームを打つことで、1レイヤーのまま文字内容を切り替えられる
- フォント、スタイル、カラー、ストローク、サイズ、トラッキング、カーニング、ストローク幅もキーフレームごとに変更できる
- ただしキーフレームはホールドのみで、イージングでつなぐことはできない

### 基本のスライドイン（Position + Opacity）
- テキストレイヤーの「テキスト」横の「アニメート」から Position と Opacity のアニメーターを追加する
- 終了時点（例：1秒）に Position と Opacity のキーフレームを置く
- 開始時点では Position を下方向に約35ずらし、Opacity を 0 にする
- 2つ目のキーフレームに F9 で Easy Ease をかける
- できたアニメーターは他のテキストレイヤーへコピー＆ペーストして再利用できる

### 応用スライドイン（文字・単語・行ごとにずらして入る）
- Position と Opacity のアニメーターを追加し、アニメーターを「Position 1」とリネームする
- Ctrl/Cmd+D で複製して「Position 2」を作る（2状態方式）
- Position 1：Position を +35（下）、Opacity を 0 に設定する
- Position 2：Position を -35 にして打ち消し、Opacity は 100 のままにする
- Position 2 のレンジセレクタで Offset をアニメーションする：-100 にキーフレーム → テキスト全体が画面に出る位置（この設定変更後は 100）まで進める
- Advanced を開き、基準（Based On）を Characters / Words / Lines から選ぶ。動画では Lines が見やすい例として使われる
- Advanced の Shape を Square から Ramp Down に変える
- Ease High を 80〜90 程度まで上げる（Ease Low を使うと逆方向のイージングになり、このアニメーションには合わないと説明される）

### Shape の理解（ピリオド列での実験）
- ピリオドを大量に並べたテキストで Position と Offset を動かすと、Shape の影響範囲が目で見て分かる
- Square：四角い影響範囲が通過する
- Ramp Up / Ramp Down：上向き／下向きのランプ状の影響範囲が通過する（見た目と名称の向きが逆に感じる、と語られる）
- Triangle：三角形、Round：丸い形の影響範囲が通過する

### フリッカーイン（Flicker In）
- 上記のスライドインの上に、新規の Opacity アニメーターを別途追加する（既存の Position 1 / 2 には入れない）
- レンジセレクタの Offset を -100 → 0 でアニメーションする
- 「Randomize Order（順序をランダム化）」をオンにして、文字がランダムな順で入るようにする
- Random Seed に Alt/Option+クリックでエクスプレッション `time * 100`（数値は任意）を入れる。数値が大きいほどフリッカーが速くなる
- アウト側はキーフレームを逆向きにコピーして作る

### Wiggly セレクタと Unicode 記号
- Position と Rotation のアニメーターを追加し、セレクタとして Wiggly セレクタを追加する
- Position（縦方向）と Rotation に量を入れて初めて文字が揺れる
- 「その他のオプション（More Options）」で文字のアンカーポイント位置を変更し、揺れの支点を選べる
- 大きなフォントファミリーは Unicode に対応するため、矢印・ポインター・スマイリー等をテキストとして入力し、Wiggly で回転させるような図形アニメーションにも使える

### アニメーションプリセットとして保存
- 保存したいアニメーターだけをすべて選択し、「アニメーション > アニメーションプリセットを保存」で Presets フォルダ（動画では Text フォルダ内）に保存する
- 適用は Effects & Presets パネル検索、または FX Console から行う
- ソーステキストなど、毎回適用したくないプロパティを一緒に選択して保存しないよう注意する

## 見た目の特徴
- 基本形は下からスライドしながらフェードインするテキスト
- 応用形は文字・単語・行が1つずつずれてスライドインし、そのままスライドアウトもできる、段落全体に使える動き
- フリッカー版は文字がランダム順にチラつきながら出現する
- Wiggly 版は文字が位置・回転ともに細かく揺れ続ける

## デザイン上の注意点
- Shape と Ease High / Ease Low の組み合わせは、ピリオド列のような単純なテキストで実験して感覚を掴むことが勧められている
- Ease の方向（High か Low か）はアニメーションごとに合う／合わないがあり、再生して確認することが勧められている
- この解説の一部は Kyle Hamrick のテキストアニメーター動画を参考にしていると明言されている
