# After Effects: Glitch Text Transitions（Creative Dojo）
- URL: https://www.youtube.com/watch?v=cbPy8fPp1Mk
- テーマ: グリッチ（エクスプレッションによる文字ランダム化トランジション）

## 技法と手順

### 前提：使うエクスプレッション
- Kyle Martinez（字幕内では Kyle Martinez と紹介）が公開したエクスプレッションを使う。記事にコード全体とブロックごとの解説があり、コードをコピーして使う
- 動画の本題はテキスト自体のブロック状ランダム化トランジションであり、画面全体のグリッチ歪みや色収差（クロマティックアバレーション）は本題外として扱われる

### スライダーコントロールの準備（名前が必須条件）
- テキストレイヤーを新規作成する（例：「glitch text」）
- Effect > Expression Controls > Slider Control を2つ追加し、複製して用意する
- 1つ目を「Posterize Time」、2つ目を「Character Offset Percentage」と正確にリネームする。エクスプレッションがこの名前を参照するため、名前を変えるならエクスプレッション側も変える必要がある
- Posterize Time：エクスプレッション全体をポスタリゼーション（フレームレートを落としたような動き）にする値。Kyle の推奨は 12、投稿者は 6〜10 程度が好みとして 10 に設定する
- Character Offset Percentage：値を 100 で割って確率（Probability）として使う

### ランダム化文字の配列（Characters）
- エクスプレッション内の Characters 配列が、置き換えに使うランダム文字の候補になる
- 字幕内では Unicode のブロック文字が投稿者の環境では動作せず、Google で調べた「full block」文字が動作したと語られる
- 動画ではブロック文字1つとアンダースコア（_）に差し替えて使っている。候補は1〜2文字でも、多数のランダム文字でも自由にカスタマイズできるとされる

### エクスプレッションの仕組み（字幕内の解説範囲）
- テキストを行（line）ごとに分割する（複数行テキストでも動作する）
- 各行について元の行を取得し、getNewLine 関数で変換した新しい行を作る
- getNewLine は1文字ずつ処理し、乱数が Probability 未満なら getRandomCharacter で配列からランダム文字を選び、そうでなければ元の文字を残す
- 最後に全行を結合して文字列として返し、それがテキストレイヤーの表示になる
- 適用方法：ソーステキストのストップウォッチを Alt/Option+クリックし、コードを貼り付ける

### 値の挙動
- Character Offset Percentage が 0：何もランダム化されない
- 50：約50%の文字がランダム化される見込みになる
- 100：全文字がランダム化される
- Posterize Time を大きな値（例：30）にするとランダム化が非常に速く、小さな値（例：1）では遅くなる

### トランジションの組み立て（消える側）
- Character Offset Percentage に 0 → 100 のキーフレームを打ち、文字がランダム化していく状態を作る
- そのままではブロック文字が残り続けるため、テキストアニメーターで Opacity を追加する
- レンジセレクタの Advanced で Smoothness を 100 → 0 に変更する
- Offset を、テキスト表示状態の 100 から、クリップ終端で 0 になるようアニメーションする。これでランダム化しながら縮むように消える
- テキストレイヤー自体もその時点でクリップ（トリム）する

### トランジションの組み立て（現れる側）
- レイヤーを Ctrl/Cmd+D で複製し、2つ目のテキスト（例：「expression」）に差し替える
- キーフレームを前方へ移動し、内容を反転させる：Opacity の Offset は 0 → 100（フェードイン）、Character Offset Percentage は 100 → 0（ランダム状態から通常の文字へ戻る）
- 全体は約1秒以内で起こる

### 仕上げ（本題外として紹介される要素）
- UI グリッド：無料プリセット「UI Grids」（Dark Paws 作、字幕表記は曖昧）を背景に置く
- デモで使われた全体グリッチは Red Giant Universe Glitch（有料サードパーティ製）。Tint で彩度を落とし、Universe RGB Separation で色収差、Optical Glow（Red Giant）のグローも追加されている
- これらは有料プラグインなしでも、ディスプレイスメントマップや RGB 分離、標準グロー、投稿者の無料ツール等で代替できると語られる

## 見た目の特徴
- テキストの文字がブロック（■状の文字）とアンダースコア等にランダムに置き換わりながら崩れ、次のテキストがランダム状態から正しい文字へ収束して現れる、ブロック状のグリッチトランジション
- 単体では効果が弱く、グリッドや全体グリッチを重ねて初めてデジタル画面らしい見た目になると説明される

## デザイン上の注意点
- スライダー名「Posterize Time」「Character Offset Percentage」の綴りはエクスプレッションと完全一致させること
- Posterize Time は 10 前後が程よいとされる（速すぎ／遅すぎの調整値）
- Unicode ブロック文字は環境によって動作しない場合があるため、動作する文字に差し替えること
