# テキストアニメーション15選 / After Effects CC2024 使い方講座（Action Planet）
- URL: https://www.youtube.com/watch?v=H2BKpouB0Y0
- テーマ: テキストアニメーター15種の作り方カタログとプリセット保存

## 技法と手順
共通操作：テキストレイヤーの「アニメーター → 追加」でプロパティを加え、「範囲セレクター」の開始／オフセットにキーフレームを打ち、必要に応じて「高度（詳細）」のシェイプ／イーズ／順序ランダム化／基準を使う。キーフレームはF9でイージーイーズ。

### 1. 落ちるテキスト（位置＋ブラー）
- アニメーター → 位置、値を-600（上方へ）
- 範囲セレクターのオフセット：0%でキーフレーム → 1秒で100%。F9でイーズ
- アニメーター1の「追加 → プロパティ → ブラー」、ブラー50程度
- ブラーの縦横比のチェックを外しXを0にして縦方向だけのブレにし、落下に合ったモーションブラー風にする

### 2. 点滅するテキスト（不透明度＋ランダム）
- アニメーター → 不透明度、0%
- 高度 →「順序ランダム化」オン。開始を90%に設定
- ランダムシードを動かすとチカチカ点滅する
- ランダムシードにエクスプレッション（Optionクリック）：`time * 20`（1秒間に20回点滅）
- 終了させたい所で開始にキーフレームを打ち100%にする。0%から上げれば点滅しながら登場も可能

### 3. ジャンプテキスト（位置＋シェイプ：滑らか）
- アニメーター → 位置、-300
- 高度 → シェイプを「滑らか（Smooth）」に変更（中心が盛り上がる形）
- オフセット：-100% → 100%でキーフレーム、F9でイーズ
- 登場用に別アニメーターで不透明度0%を追加し、ジャンプに合わせてオフセット0%→100%

### 4. 広がるテキスト（トラッキング／字送り）
- アニメーター →「字送り（トラッキング）」
- トラッキング量にキーフレーム、マイナス方向で中央寄せ配置 → -10でキーフレーム
- エクスプレッション：`value + time * 5`（現在の値に1秒あたり5ずつ加算し、広がり続ける）
- F9でイーズ、グラフエディター（速度グラフ）で冒頭速く徐々に失速する形に調整。横ブラーの追加も応用として紹介

### 5. 色づくテキスト（塗りのカラーRGB＋不透明度）
- アニメーター → 塗りのカラー → RGB、色を白に変更。同じアニメーターに不透明度0%も追加
- 高度 → 滑らかさ0%、順序ランダム化オン。開始0%→100%で点滅しながら登場。グラフエディターで最初速く点滅する形に
- 別アニメーターで塗りのカラーRGBを好きな色で追加し、同じく滑らかさ0%／ランダム化オン／開始キーフレームをずらすと部分的に色が付く
- 複数色はアニメーターを複製し、色変更＋ランダムシードをずらす

### 6. フェードするテキスト（ブラー＋単語基準）
- アニメーター → ブラー、30程度。オフセット0%→100%で右から出現
- 高度 → 基準を「単語」にすると単語ごとにブラーで出現
- 消える動き：終わりでオフセット-100%（字幕では-1%とも聞こえる箇所あり、曖昧）にキーフレーム。止めたいキーフレームは右クリック→「停止したキーフレームの切り替え（Toggle Hold）」で値を保持し、最後に0%で再びブラーがかかる
- 不透明度0%も同様に追加。仕上げに字送りで広がる動きも組み合わせている

### 7. 弾むテキスト（位置＋下へ傾斜＋イーズ）
- アニメーター → 位置、-100。オフセット-100%→100%
- 高度 → シェイプ「下へ傾斜」、イーズを高く（Ease High）100%で後半を滑らかに
- アニメーター1をコピー＆ペーストしてアニメーター2を作り、位置Yを50、イーズ高く／低くを各50%にすると、上がった後に滑らかに少し下がる動きになる。オフセットのタイミングを少しずらすと印象が変わる
- 不透明度0%のアニメーターも追加し、弾みながら登場させる

### 8. 拡大テキスト（スケール）
- アニメーター → スケール、0。オフセット-100%→100%（字幕では開始-1%とも聞こえる）
- 高度 → シェイプ「上へ傾斜」、イーズ高く50%／イーズ低く50%で始めと終わりを滑らかに
- 細かい緩急はF9＋速度グラフで調整

### 9. 3Dブラーテキスト（文字単位の3D化）
- アニメーター →「文字単位の3D化を使用」を有効化（文字ごとにバラバラに3D化）
- 位置を追加（X/Yに加えZ軸が出る）。追加で不透明度とブラーも入れる
- 位置Zを-2000（手前側）。高度 → シェイプ「上へ傾斜」、イーズ低く100%で始まりをゆっくりに
- オフセット-100%→100%で奥へ向かう動き。不透明度0%＋ブラーを上げると柔らかく登場する

### 10. 伸縮テキスト（スケールY）
- アニメーター → スケール、縦横比のチェックを外しYを0%（縦に潰れて見えなくなる）
- 高度 → シェイプ「上へ傾斜」、イーズ低く100%
- オフセット-100%→100%
- アニメーター1をコピーしてアニメーター2を作成。アニメーター1のオフセットキーフレームを少しずらし、アニメーター2側のスケールYを200%まで上げると「上に伸びてから通常に戻る」ポヨンポヨンした動きになる。F9／速度グラフで調整

### 11. 回転テキスト（文字単位の3D化＋回転）
- 「文字単位の3D化を使用」を有効化 → アニメーター → 回転、X回転を90度
- 範囲セレクター（字幕では「回収」と誤認箇所あり）でキーフレーム → 100%
- 追加で不透明度0%を入れ、透明な状態からパタパタ起き上がる動きにする

### 12. 入れ替えテキスト（位置＋マスク＋単語基準）
- アニメーター → 位置、Yを150程度（下に配置）
- 高度 → イーズ低く100%（始まりゆっくり）、基準を「単語」
- オフセット-100%→100%（字幕では-1%とも聞こえる箇所あり）
- 表示範囲を長方形ツールで囲んでマスクし、アニメーターで動く文字がマスク外で隠れるようにする。F9でイーズ
- 隠れた所でCtrl+Shift+D（MacはCmd+Shift+D相当）でレイヤーを分割し、後ろのレイヤーの文字を変更すると、隠れた後に別の言葉が出てくる。テキストを若干重ねると同時アニメーションでより良い感じになる

### 13. ランダムテキスト（位置＋ウィグルセレクター）
- アニメーター → 位置、-300程度
- 追加 → セレクター →「ウィグル（Wiggly）」を適用すると縦方向に踊る動きになる
- ウィグルセレクターを開き、相関性と「ウィグル/秒（Wiggles/Second相当）」を両方0にして動きを止める（＝バラバラな静止位置だけ残る）
- 範囲セレクター側：高度 → シェイプ「上へ傾斜」、イーズ低くを上げて最初ゆっくりに。オフセット-100%→100%でバラバラの文字が中央に集まる
- 登場用に不透明度0%のアニメーターを追加し、オフセット0%→100%

### 14. スライドテキスト（位置X＋ブラー＋エクスプレッション）
- アニメーター → 位置、Xを上げて横に移動。高度 → シェイプ「上へ傾斜」。オフセット-100%→100%、F9／速度グラフで冒頭だけ速く
- 位置の下にブラーを追加、縦横比を外してXの値を上げ、入ってくる時に横向きのブレで勢いを付ける
- 常時動かす用にアニメーター2で位置を追加し、位置にエクスプレッション：配列で囲み、Xはtime系の式でマイナス方向へ、Yは0のままにする（字幕では具体的な式は断片的）

### 15. コードテキスト（文字コード）
- アニメーター →「文字コード」を追加（補足：その上の「文字のオフセット」は全文字バラバラに切り替わるもの。文字コードは全て同じ文字に切り替わる）
- 文字コードの値を上げると別の文字が表示されるので、線（記号）が並んだ状態にする
- 開始にキーフレーム → 100%になるよう値を上げると左から順に元の文字に戻る
- ブラー追加、縦横比を外して縦方向ブラーを加えるとコロコロ現れる表現になる

### プリセット保存
- 作成したアニメーターを選択した状態で、アニメーション →「アニメーションプリセットを保存」
- 保存先をプリセットフォルダーに入れるとエフェクト＆プリセットに表示される。マスクやフォントも反映して保存できる場合がある

## 見た目の特徴
- 15種はいずれも「範囲セレクターの範囲が移動するのに合わせて、位置／不透明度／スケール／色／ブラー等が1文字（または単語）ずつ変化する」見た目が基本
- シェイプ（上へ傾斜／下へ傾斜／滑らか）とイーズ高く・低くの組み合わせで、出現の波形（最初ゆっくり／最後ゆっくり／中央が盛り上がる）が変わる
- ブラー、ランダム化、ウィグル、3D化、文字コードを組み合わせると、点滅・バラバラ集合・奥行き移動・デコード風など表現の幅が広がる

## デザイン上の注意点
- 登場（不透明度）と本体の動きはアニメーターを分ける。オフセット値やタイミングが異なるため、と3番などで明言されている
- アニメーター同士の組み合わせで表現が増えるので、いろいろ試すことが勧められている
- 練習先として歌詞動画やスライドアニメーションが挙げられている
