# バウンドテキストアニメーションの作り方（TETERON）
- URL: https://www.youtube.com/watch?v=3Y6kNVNxVfs
- テーマ: テキストアニメーターの位置＋シェイプ（上へ傾斜）重ねがけによるバウンド

## 技法と手順

### 準備
- Ctrl/Cmd+Nで新規コンポジション、名前「バウンドテキスト」、デュレーション10秒
- Ctrl/Cmd+Yで新規平面、名前「BG」、色は好みでよい
- Ctrl/Cmd+T（または文字ツール）でテキスト入力（例：「BOUND TEXT」）、フォントは動画では「Raleway」を使用。文字の色は白
- 整列で中央に配置

### バウンド本体（アニメーターを3段重ねる）
- テキストレイヤーの「アニメーター」から位置を追加する（字幕では単に「1を追加」と聞こえる箇所があるが、文脈は位置）
- アニメーター1：
  - 位置の値を180に設定（下方向へ大きく。符号の向きは字幕の説明「最初下から来るように設定」に基づく）
  - オフセット：-100%でキーフレーム → 1秒15フレーム付近で100%
  - 高度（詳細）→ シェイプ「上へ傾斜」、イーズを低く（Ease Low）を100%
- アニメーター2（アニメーター1をCtrl/Cmd+Dで複製）：
  - 位置をマイナス方向に振り、-100程度に設定（上に行く動きにするため、開始点より少ない数値でマイナスに振り切る、という説明）
  - 高度 → イーズを低く／イーズを高くを各50%
  - これで「ボヨーン」とバウンドする感じになる
- アニメーター3（アニメーター2をさらに複製）：
  - 位置を今度はプラス方向に振り、100より少ない数値で50くらいに設定
  - 高度 → イーズを低く0%、イーズを高く30%程度
  - 3段の重ねがけでバウンドの余韻が完成する

### 仕上げの追加（任意）
- アニメーター1に「追加 → プロパティ → 不透明度」を追加し、不透明度を0にすると、バウンドしながらフェードインする
- 代わりにスケールを追加して0%にすると、スケール0から出現する見た目にもできる。いろいろ試してカスタムするよう勧められている

## 見た目の特徴
- 文字が下から1文字ずつ上がってきて、行き過ぎて戻る「ボヨーン」という弾んだ動きを3段階で繰り返し、徐々に静止する
- 可愛くてシンプルな印象のテキストアニメーション

## デザイン上の注意点
- フォントは丸っこくて可愛い感じのものが良い。細いフォントを選ぶ場合は太くする
- 筆記体は選ばない方が見栄えが良くなる、と述べている
