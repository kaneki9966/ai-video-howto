# グリッチテキストの作り方（AEチャンネル/てつ）
- URL: https://www.youtube.com/watch?v=k2SQa9oXhic
- テーマ: フラクタルノイズのマット＋ディスプレイスメントマップ＋RGB色ずれによるグリッチ

## 技法と手順

### 準備：テキスト
- 新規コンポジション、名前「オール（ALL相当）」、デュレーション3秒
- テキスト入力（例：「グリッチ」）、中央配置、サイズを少し大きく。フォントは動画では「SHMP」と字幕にあるものを使用（表記は自動字幕で曖昧）
- テキストの「アニメーター」から「歪曲（Y歪曲相当）」を追加し、数値を10くらいにして少し角度を付けた文字にする
- テキストを右クリック → プリコンポーズ、名前「テキスト」

### 1. マット用コンポジション（フラクタルノイズ）
- 新規コンポジション、名前「マット」、デュレーションは10秒と長めに取る
- Ctrl+Yで新規平面、名前「マット」
- エフェクト → ノイズ＆グレイン →「フラクタルノイズ」を追加
  - ノイズの種類は4種類のうち一番上の「ブロック」
  - コントラスト：100 → 400（白黒をパキッとさせる）
  - トランスフォームを開き「縦横比を固定」のチェックを外す
  - スケールの幅を450くらい（横に伸ばす）、スケールの高さを45くらいに小さくする
  - 展開のオプション → ランダムシードにエクスプレッション：Alt（MacはOption）クリックで `time * 10` を入力し、ジャギジャギした模様が動き続けるマットにする

### 2. ディスプレイスメントマップで歪ませる
- 「オール」コンポジションに戻り、マットコンポジションを追加（表示はオンのまま）
- Ctrl+Alt+Yで調整レイヤーを追加し、エフェクト「ディスプレイスメントマップ」を適用
- ディスプレイスメントマップレイヤーを「マット」に設定
- 最大水平置換／最大垂直置換（字幕では「最大水平／垂直置き換え」）を両方0にしてキーフレームを打つ
- 1〜3フレーム間隔で計5個のキーフレームを打ち、真ん中付近のキーフレームで値をずらす
  - 例：最大垂直置換を-65くらい＋水平も付けて斜めの歪みにする。3フレーム目など他のキーフレームも違う値にする
- 全キーフレームを選択 → 右クリック →「停止したキーフレームの切り替え」でカクッとしたグリッチの動きにする
- 完成したキーフレーム群を複製し、1秒18フレームの位置に貼り付けると、終わりが2秒付近に来てグリッチが2回起きる構成になる

### 3. テキスト自体の点滅（フリッカーイン）
- 「テキスト」コンポジション内に入る
- アニメーションプリセット → テキスト → アニメートイン →「不透明度フリッカーイン（Flicker In相当）」を追加
- Uでキーフレームを表示。後ろの4つは削除し、全選択してAltを押しながら左へ移動し、終わりが1秒付近に来るよう調整。1秒でAlt+]で終わりを切る
- Ctrl+Dで複製し、右クリック → 時間 →「時間反転レイヤー」でアウト（消える）動きを作り、一番後ろに配置。前後を伸ばして再生すると「出てきてチカチカ、チカチカして消える」動きになる

### 4. RGB色ずれ（チャンネルシフト）
- 「オール」に戻り、テキストレイヤーの名前を「レッド」に変更
- エフェクト → チャンネル →「チャンネルシフト」を追加し、赤以外を「フルオフ」にして赤だけ表示
- Ctrl+Dを2回押して複製し、上を「グリーン」「ブルー」と名付け、ラベル色も合わせる
  - グリーンは緑だけ表示（赤・青はフルオフ）、ブルーは青だけ表示
- ブルーとグリーンの描画モードを「スクリーン」に変更
- レッドレイヤーの位置（P）にキーフレームを打ち、グリッチしているキーフレームの位置に合わせて位置をランダムにずらす（左にずらしたら次は右上に、下だけ少し、オーバー目に、逆方向に少し、など）。これでよく見るグリッチの色ずれが作れる、という理屈が説明されている

### 仕上げ
- お好みで見本のようにSE（効果音）を追加してデジタルっぽいグリッチ感を作る

## 見た目の特徴
- 横長に引き伸ばされたブロックノイズのマットで文字が瞬間的に斜め／横にズレて歪む
- 出現・消失時は不透明度がチカチカと点滅する
- グリッチの瞬間だけRGBが分離して色ずれが見える

## デザイン上の注意点
- 汎用化のコツ：テキストコンポ内の文字を打ち替える時は、中央揃えで元の文字と同じ位置にすること。位置が同じなら違う文字でも同じグリッチが使える
- ディスプレイスメントの値のずらし方は「お好み」で、動きを見ながら調整してよいとされている
