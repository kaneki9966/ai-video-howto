# Typography Motion Graphics Animation in After Effects - Kinetic Typography（Motion Nations）
- URL: https://www.youtube.com/watch?v=UahA-6QYfC0
- テーマ: キネティックタイポグラフィ（3Dカメラワーク型）

## 技法と手順

### セットアップ
- 新規コンポジション「main」：1920×1080、30fps
- 背景として Solid を新規作成し、わずかにオフホワイトの色にする。誤って動かさないようロックする
- 使用フォントは字幕では「moner black」と聞き取れるもの（自動字幕のため正確な綴りは曖昧）。色は少し暗めにする
- Align パネルでテキストを中央揃えにし、Ctrl を押しながらアンカーポイント用アイコンをダブルクリックしてアンカーポイントを中央に置く

### マスク＋トラックマットによる出現（1つ目・2つ目のテキスト）
- テキストを覆うマスク／シェイプを Shape ツールで描く
- Position にキーフレームを打ち、最終位置を決めてから、開始時点ではテキストを上（または横）へずらす
- トラックマットをそのシェイプレイヤーに設定する（ピックウィップで指定）。旧バージョンではシェイプを上に置いて Alpha Matte を使う形になると説明される
- これによりテキストはシェイプの内側にあるときだけ見える
- キーフレームを選択して F9 を押し、グラフエディタを開く。Value Graph ではなく Speed Graph を使うよう注意される。ハンドルを引いてイージングの形を作る
- 2つ目のテキストは、テキストレイヤー＋マット用レイヤーを両方選択して Ctrl+D で複製し、文字を差し替えて作る。U キーでキーフレームを表示し、複製元とイージングを揃え、トラックマットの参照先を新しいマットに直す

### 3D化と Null による全体カメラワーク
- すべてのテキストレイヤーを 3D 化する
- Layer から Null Object を追加し、Null も 3D 化する
- Top ビューに切り替え、Null をテキスト群の後方に配置してから Active Camera ビューに戻す
- 全レイヤーを選択して Null にペアレントする（Parent 列が見えない場合は右クリック → Columns で表示）
- Null に Position、Scale、Rotation（主に Y Rotation。Z Rotation は使わないが任意）のキーフレームを打つ
- キーフレームを後ろへずらし、その時点で Null を Y 軸方向に回転させて、次のテキストが見える向きへ全体を回す

### 側面テキスト（90度回転したテキスト）
- テキストレイヤーを Ctrl+D で複製し、一番上へ移動、マットを外し、キーフレームも削除する
- R キーで Rotation を表示し、90°回転させる
- Top ビューで既存テキストの真横に配置し、Active Camera に戻る
- Paragraph パネルで左揃え（Left Justify）に変えると、入力基準が中心ではなく左側になる
- Pan Behind（アンカーポイント）ツールでアンカーポイントを上部／端へ移し、S キーの Scale を 0 → 大きく、でスケールインさせる。色も Character パネルで変更する
- Null 側のキーフレームにも F9 をかけ、グラフエディタで両端のハンドルを寄せた形に統一する

### テキストを増やしていく繰り返し手順
- 既存テキストを Ctrl+D で複製 → 文字と色を差し替え → 下／横へ配置 → 大きくスケールする
- Null を Scale ダウン／移動／回転させてそのテキストへ寄せ、Position 等のキーフレームを追加する
- 必要に応じて X Rotation を少し付け、Scale ダウンと上方向への移動を組み合わせる
- グラフエディタの形は毎回、前回と「まったく同じ形」に揃える（F9 → ハンドル調整）
- アンカーポイントを角や端に置くことで、スケールの起点（どの辺から伸びるか）をコントロールする
- 特定の1文字へ寄るようなズームインも、Null の移動＋スケールで作る

## 見た目の特徴
- 最初はマスクの内側からテキストがスライドして現れる平面の動き
- 後半はテキスト群全体が3D空間に配置され、Null の回転・移動・スケールでカメラが次々と別の単語へ回り込んでいくような、奥行きのあるキネティックタイポグラフィになる
- 単語ごとに大きさ・色・角度が違い、最後にドラマチックな寄りの動きが入る

## デザイン上の注意点
- この種のアニメーションはボイスオーバー（ナレーション）に合わせると効果的とされ、単語の速さに合わせてキーフレーム間隔を速く／遅く調整することが勧められている
- グラフエディタでは Value Graph ではなく Speed Graph を使うこと
- イージングのグラフ形状はテキストごとに揃え、タイミングは再生しながら調整する前提で語られている
- サードパーティ製プラグインは使わない
