# 手順書：Claude Codeで自分のAI編集者を作る（海外・完全自動化）

出典動画：YouTube「How I Edit My YouTube Videos With Claude Code (Fully Automated)」（https://youtu.be/wrZpU_VfHp4 、18:08）
字幕テキスト：transcript.txt（同フォルダ、英語字幕のまま）

## 概要
- 1本750ドルで外注していたYouTube編集者を解雇し、Claude Codeで自分のAI編集者を構築した手順。セットアップは1時間以内、費用は月20ドル程度から
- 20分の撮って出し素材を渡すと、13分程度の仕上がったYouTube動画が返ってくる
- 核心は「素のClaude Codeだけではダメ。スキルとMCPで“耳・目・デザイン”を与えてジュニア編集者として育てる」こと

## 必要なものと費用
- Mac（空き容量50GB以上。外付けHDDでも可）
- Claude Pro（月20ドル）または Max（月100ドル〜）。たくさん使うならMaxを推奨
- ElevenLabs APIキー（音声→文字起こし。約0.2ドル/時間。Speech to Textの権限だけをオンにする）
- HyperFrames（無料。モーショングラフィックス・キャプション・アニメーション担当）
- Watchスキル（無料。Claudeが動画を「見る」ためのプラグイン）
- Homebrew・FFmpeg・Node・uv・yt-dlp（無料）

## 各ツールの役割
- ElevenLabs＝「耳」：単語単位の正確なタイムスタンプ付き文字起こしをする。これがないとカット位置がずれ、単語が切れる
- HyperFrames＝「デザイナー」：モーショングラフィックス・キャプション・アニメーションをHTMLとして書き、レンダリングする
- Watchスキル＝「目」：動画のフレームを見て、話者の視線や画面の内容を理解する。ないと推測で編集することになる
- FFmpeg＝カット・同期・結合・書き出しの実務担当

## セットアップ手順
1. Claudeのデスクトップアプリを入れ、サインインしてプランを選ぶ。Chat／Co-workではなく「Code」タブを使う
2. プロジェクトフォルダを開き、Claudeにセットアップコマンドを実行させる（Homebrew、ffmpeg、node、uv、yt-dlpのインストール）
3. ElevenLabsを接続する：elevenlabs.ioでAPIキーを作成（Speech to Textのみオン）。**キーはチャットに直接貼らず、ターミナル経由でMCPに追加する**（`claude mcp add elevenlabs`）。設定後にClaudeを再起動し、接続を確認する
4. デザイナーと目を入れる：ターミナルからHyperFramesとWatchスキルをインストールする
5. 編集者用のワークスペースを作らせる：Raw Footage／B-roll／Music／Sound Effects／Inspiration／Projects／Exportsのフォルダ構成。素材は外付けHDDでもよく、場所をClaudeに教える
6. （上級テクニック）音楽をムード・BPM・エネルギーでカタログ化させると、動画ごとに合う曲を自動で選んでくれる

## 初めての編集の進め方
1. 素材をRaw Footageフォルダに入れ、「YouTube動画を作って。ElevenLabsで文字起こしして、無音・えー・ミス・撮り直しを全部切って、仕上がった動画にして」と頼む
2. 目線も見ている：カメラを見ている時は全画面、ホワイトボードを見たら話者を隅に小さく表示する、といった切り替えも自動で判断する
3. 一発では完璧にならない。デザイン（モーショングラフィックス・効果音）を追加で指示し、参考動画を2〜5本渡して「この人たちのペースとキャプション様式を混ぜて自分のスタイルにして。1人だけをコピーしないで」と頼むと、独自のスタイルになる
4. 数字を言う場面では、Claudeが自分でWebから実際のスクリーンショット（Frame.ioやCalendlyの画面など）を取ってきて差し込む。「results」フォルダに実績画像を入れておくと、クライアントの実績を言及した時に自動で引っ張ってくる

## 修正を安く・正確にするコツ（Frame.io式プレビュー）
- 毎回フルレンダリングして直すのはクレジットの無駄。Claudeに「Frame.io風のプレビューアを作って」と頼み、タイムスタンプ付きで修正メモを付けられる画面を用意させる
- 修正は「3秒のところで〜」「0.6秒で〜」のようにタイムスタンプ付きでメモし、まとめてClaudeに送る。これで修正が速く・正確になる
- 納得したらフルレンダリングする。サムネイルもClaudeに作らせられる

## スキル化して育てる（最重要）
- 1本作ったら必ず「今やったこと全部（ブランド・キャプション様式・B-roll・音楽ルール・プレビュー手順・修正内容）を『YouTube Editor』というスキルにまとめて」と頼む
- 次回からは「YouTube Editorスキルで新しい録画を編集して」と一言で済む。改善したら「スキルを更新して」と伝えて育てていく
- これをしないと毎回ゼロから説明することになる

## 自分たちへの応用
- 構成は私たちの既存の手順書（XhEGWsmuIhM、RwynWBXuRaA、sSioCgXjKnI）とほぼ同じ結論：「耳（文字起こし）＋目（フレーム確認）＋デザイナー（HyperFrames／Remotion）＋スキル化」がAI編集の型
- 無料・ローカル方針での置き換え：ElevenLabsはWhisperX（ローカル無料）に置き換え可。Claude Codeは有料プラン必須だが、MaxではなくPro＋無料ツールで始めるのが現実的
- 「Frame.io式プレビューで修正メモをタイムスタンプ付きで送る」は、私たちのRemotion試作の修正フローにもそのまま使える良い習慣
