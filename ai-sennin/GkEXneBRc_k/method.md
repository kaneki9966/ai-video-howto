## 主な主張

### 1. 各AIの強み（2026年秋時点の本人の整理）
- **Gemini**：処理の速さ、日本語文章の自然さ（AI特有の定型表現の少なさ）、Google Workspace連携。
- **Claude（Claude Code / Fable）**：曖昧で雑な指示や目的から本質・真の意図を汲み取り、要件整理して形にする力が高い。
- **Astra**：視覚情報・3D空間把握・UI理解・PC操作・ロボット制御（VLA／フィジカルAI）など「目と手」の領域で進化が際立つ。思考強度を下げると空間把握等の強みが落ちやすいためプラン選びが重要。
- **Grok / Grok Bot**：スマホ完結の手軽さ、行動力、コスパ。一方でデータや決済・情報収集への姿勢から機密情報の扱いは注意。
- **Cursor等**：クラウドエージェントとしての開発環境、複数モデル・低コスト志向の選択肢。
- **根拠の種類**：実体験ベースの所感整理。ベンチマーク等の提示なし。

### 2. 課金の結論は「正直アストラ」（32:59、38:41）
- **主張**：タイトルの問い（結局何に課金すべきか）への本編の結論は「課金するならアストラ」「正直アストラかな」。Fableについては「Fable無限課金や。マジ」（24:05）という言い方もあり、タスク次第で際限なく課金したくなる魅力がある、という文脈。
- **根拠の種類**：実体験の所感。価格体系の比較表等の提示なし。
- **注意**：Geminiまとめではこの結論が独立項目として明示されず、「目的に応じてAstraやFableを選ぶ」という一般論に埋没していた（下記照合結果参照）。

### 3. 中国AIをめぐる速報（10:02〜）
- **主張**：Claude（Anthropic）から「衝撃的なレポート」が出たという速報。中国のAIモデルがClaude Codeを学習して作られたと噂されていた件と、中国のユーザーが自前モデルで答えると見せかけて実際はAnthropicに流していた（＝実質ただのClaude Codeだった）というニュースを紹介。
- **根拠の種類**：レポート・ニュースの伝聞。本人も「因果関係とか謎なんやけど」と留保。レポート名・発行日・一次情報の提示なし（既存調査で繰り返し見られた速報回の弱点と同型）。

### 4. まず「80点」を取れる状態を作れ（14:35〜）
- **主張**：基礎的なコーディング・自動化で80点を取れる状態を作ることが先決で、それはローカルLLMや中国のモデルを極めるより、正しい知識があればはるかに安いコストで簡単に到達できる。「80点取れたら今のAIの案件なんてボコボコ取れるし、社内の仕事も大体全部自動化できる」。ローカルLLMや中国系モデルはその後の段階・限定用途。
- **根拠の種類**：持論＋案件感覚の自己申告。「80点」の測定基準は示されない。

### 5. 辛口評価：NotebookLM等（18:16〜）
- **主張**：NotebookLMは「他のYouTuberがよく推す」が、スライド等はHTMLで出せばよく、Astraを使えば大体NotebookLMでやれることはやれる、という評価。GensparkやManusの流行にも言及し、用途と到達点を見て選ぶべきという立場。
- **根拠の種類**：所感。

### 6. 「解きたい問い」を見つけることが重要
- **主張**：課金先の選択以上に、AIにやらせる高難易度・高インパクトな「問い」を日常の観察・インプットから見つけ、AIと一緒に探り続けることが重要。
- **根拠の種類**：持論。既知の主張①（何をやらせるかが重要）の言い換え。
