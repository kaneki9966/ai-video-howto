# 手順書：川村式AI動画編集（カット済み素材＋デザイン＋マニュアルをAIに渡す）

出典動画：AI動画編集のすゝめ／河村風真「全ての動画編集者に捧ぐ、僕の3年間を全てここに詰め込みました」（https://youtu.be/fysJODomfF4 、25:24）
字幕テキスト：transcript.txt（同フォルダ）

## 考え方
- 人間がやるのは「カット」と「最終チェック・調整」だけ。残り9割はAI
- 編集時間を10時間→1時間に短縮（同社の実績：月60本以上の長尺動画、編集者12〜15人→3人、月50万円以上の削減）
- カットの質が全てを決める。カットがずれるとテロップも演出もずれて品質が落ちるので、カットだけは人間が100点を目指す

## AIに渡す3点セット
1. **カット済みプロジェクト**：Premiereで無音カット（自作プラグイン「Cut&SRT」で高速化）＋手動で仕上げたカット済み素材を、プロジェクトマネージャーでまとめたPRPROJ
2. **デザインPM**：そのチャンネルで使うテロップデザイン・効果音・テーマ・ポイントなどを部品としてまとめたPremiereプロジェクト
3. **編集マニュアル**：テロップ／強調のルール、どのトラックに何を置くか等を言語化したドキュメント（文字＋画像が入れば形式は自由）

## 手順
1. 素材をPremiereに入れ、無音カット＋手動調整でカットを完成させる
2. カット済みプロジェクト、デザインPM、マニュアルの3つをAIエージェント（Claude Code / Codex等）に渡し、専用スキル（SKILL.md）を発動させる
3. AIはマニュアルを全文読み、デザインPMの部品を使ってテロップ・演出を入れ、**別名のPRPROJとして書き出す**（Premiereは起動せずプロジェクトファイルを直接組み立てる）
4. 人間がPremiereで開いて確認し、強調したい箇所やタイミングを最終調整する

## ポイント
- 出力がMP4ではなくPRPROJ（編集可能なプロジェクト）なのが重要。テロップの文字もキーフレームも後から直せる
- 冒頭ダイジェスト（アバン）のテロップは空にしておき、人間が入れる（動画の視聴継続を決める最重要部分のため）
- マニュアル作成もAIでできる：デザインPMとスキルを渡すと、AIがコンピュータ操作でPremiereを開き、デザイン箇所のスクショを撮ってマニュアルに組み込む
- スキルは配布物をもらって終わりではなく、自分のチャンネル・運用に合わせて書き換えて成長させるもの
- モデルは高性能クラス＋高エフォート推奨（字幕では「オーパス」「GPTソル」系と発言。低価格モデルは安定しないとのこと）※モデル名は字幕の音声認識ママ
- 隠し部分への効果音（ピロピロ音）などもAIが自動で入れる

## 自分たちへの応用
- Premiereは使わないが、型はそのまま使える：「素材＋デザイン部品（テロップ色・フォント・SE集）＋編集マニュアル」を金木さん専用テンプレートとして用意しておけば、素材を渡すだけで同じ形式の編集を再現できる
- もしも系動画のテンプレート化（Kzo0d_aLULQの手順書）と同じ発想。ジャンルごとにマニュアルを蓄積していく
