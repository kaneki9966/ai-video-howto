# Photoshopパーツ分けをAEへ渡す準備 — レイヤー構造は「最初の読み込み前に確定」が鉄則

## テクニック・手法の概要
- AEはPSDの個別レイヤー・レイヤースタイル・透明部分・レイヤーマスク・調整レイヤーを保持して読み込める（①Muse直接確認／裏取り済み：Adobe公式）。
- 読み込みの成否はAE側の操作ではなく、PSD側の事前整理（命名の一意性、レイヤー順、RGB、互換性設定）でほぼ決まる。特に「読み込み後にPhotoshopでレイヤー名を変える／レイヤーを消すと、AEのプロジェクトパネルでMissingになる」ため、レイヤー構造は初回読み込み前に確定させる（①／裏取り済み）。

## 再現手順（設定値つき）
1. 新規ドキュメントは File > New の Film & Video プリセットから作る（例：HDTV 1080p、4KならFilm(4K)）。最初から出力サイズに合わせる。
2. 色モードを RGB にする（Image > Mode > RGB Color）。AEはRGBネイティブで、CMYKは自動変換されるが事前にPhotoshopで直す方が処理が速い。
3. カラープロファイルは Edit > Assign Profile で出力に合わせる：HDなら Rec. ITU-R BT.709、SDなら Rec. 601。
4. レイヤー命名は内容が分かる一意の名前にする（例：「Foreground Tree」「Background Sky」形式）。同名レイヤーはAE側の誤認の原因になる。
5. レイヤーの並び順を、AEコンポジションで表示したい順にPhotoshop側で揃える。
6. 一緒に動く単位はSmart Objectにまとめる（例：前景一式、背景一式）。AEでは1単位として奥行きや連動した動きを付けられる。
7. 互換性設定：Photoshop > Settings > File Handling（Mac）で「Maximize PSD and PSB File Compatibility」を Always にする。これが無いとAEがレイヤー情報を正しく読めない場合がある。
8. 色補正・拡大縮小・切り抜きは読み込み前にPhotoshopで終える。PSD形式で保存する。
9. 読み込み後にレイヤーを追加する可能性がある場合は、初回読み込み前に少数のプレースホルダーレイヤーを入れておく（旧来のAEマニュアル系の助言。本日読んだ現行公式ページには明記が無かったため、裏取り状態は未検証・暫定として扱う）。

## 必要なツール・機能（有料のものがあれば価格とともに明記）
- Photoshop＋After Effects（Adobe Creative Cloud。本人はMac版AE 2026を所有済み）。追加の有料プラグインは不要。

## AIについて分かったこと
- この工程はAI生成ではなく「データ構造の設計」であり、生成AIで作ったキャラ絵も、レイヤー命名と分割単位が曖昧だと下流のAE工程で機械的に壊れる（Missing化）。生成の質と同等に、受け渡しデータのスキーマ（命名・順序・単位）を先に固定することが自動化全体の成否を決める（③Museの解釈）。
- Smart Objectという「まとめて1単位にする」抽象化は、エージェントに仕事を渡す時のタスク分割（1単位で動く塊に切る）と同じ考え方で使える（③）。

## 金木さんへの応用
- 本編キャラの三面図→パーツ分けでは、この手順をチェックリストとして先に固定する：①パーツ名の一覧を先に決める（髪前／髪後／顔／目／腕左右／胴／羽等、重複なし）②PSDのレイヤー順＝AEでの前後順に揃える ③読み込み後の改名・削除は禁止し、直すなら再読み込み前提にする。
- 勉強会第9弾「Photoshopパーツ分けの実演」の出口（パーツ分け要件への逆算）に、そのまま要件リストとして接続できる。
- パペット側の要件（前項 method）との接続：髪のように波を伝えるパーツは分割せず1レイヤー、関節で折るパーツ（腕等）は関節単位で分割、という切り分け基準とセットで使う。

## 検証メモ
- 食い違い：現行公式ページは「レイヤー名変更でもMissingになる」と注意する一方、旧マニュアル系は「改名してもリンクは保持され、削除だけがMissing」と説明しており、バージョンで挙動が違う可能性がある。実務上は安全側（改名も削除も読み込み後にしない）で統一する。
- 未実証の範囲：自分の天使キャラ素材での読み込み検証は未実施。Smart Object化したパーツにパペットを掛けた場合の挙動も未確認。
- 確認できなかった点：フォルダ（グループ）がAEで入れ子コンポになる等の詳細は、現行公式ページの範囲では未記載（二次出典のみ）のため採用していない。
