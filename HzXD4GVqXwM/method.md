# 手順書：Claude Codeで動画編集を完全自動化する（海外・7つの仕事分担）

出典動画：YouTube「I Fully Automated My Video Editing Using Claude Code (Full Walkthrough)」（https://youtu.be/HzXD4GVqXwM 、16:58）
字幕テキスト：transcript.txt（同フォルダ、英語字幕のまま。YouTube側のレート制限のため yt-dlp ではなく TubeToTranscript 経由で取得した自動生成字幕）

## 概要
- 寝ているあいだにClaude Codeシステムが編集した動画の裏側を公開するウォークスルー。投稿者はコードが書けないが、タイムラインを触らずにカット・音・演出まで自動化している
- 考え方の核心：動画制作を7つの仕事に分け、それぞれにツールを割り当て、Claude Codeがプロジェクトマネージャーとして統括する。人間の仕事は「録画」と「フィードバック」だけ
- 実績：2分46秒の撮って出しフックを31秒にカット。公開まで3〜7日かかっていたのが当日中にできるようになった

## 7つの仕事とツール
1. **編集者（プロジェクトマネージャー）＝Claude Code**：タイムラインの前に座り、クリップを見て選び、切り、ズームやグラフィックの位置を決める。デスクトップ版を使い、ローカルで動かす（自分のパソコンのファイルにアクセスし、他のプログラムを使い、出力フォルダに結果を置く）。他のツールすべての調整役
2. **文字起こし担当＝Parakeet**：音声を聞いてテキスト＋タイムスタンプに変換する。NVIDIA製の無料ツール。Claudeはこれを読んで「何を・いつ言ったか」を知り、正しいテイクを切り出せる
3. **アニメーター＝HyperFrames**：タイトル・ロゴ・モーショングラフィックスを作る。昔はAfter Effectsが必要だったが、HyperFrames（HeyGen製・無料）ではClaudeがアニメーションを小さなWebサイトのように書き、4K動画に変換する。自分のパソコンで動くので無料
4. **リサーチャー＝Chromeブラウザ**：「OpenAIが発表した」と言ったときに、その発表のスクリーンショットやXの投稿、論文を取ってきてB-rollにする。Claudeがブラウザを使ってWebページをスクロール録画したり、行をハイライトしたり、特定部分にズームしたりできる。事実は元の投稿・ページそのままを表示する
5. **画面編集担当＝Tella**：画面収録＋顔出しを同時に録画するツール。MCPコネクタでClaude Codeに直結し、カット・ズーム・レイアウト・整形をClaude経由で操作できる
6. **サウンドデザイナー＝Epidemic Sound**：BGMと効果音を選ぶ。有料（月9.99ドル、年払い）。Claudeに接続し、音源を検索させる。好みも学習させる（フックは少しサスペンス風に、その後アップビートなlo-fi hip-hopを小さめの音量で、など）
7. **仕上げ担当＝FFmpeg**：全パーツを結合し、黒画面や音ズレがないかチェックする。無料。20年以上使われている、ほぼすべての編集ソフトの裏側にあるツール

## 一番大事なもの：スキル（編集スタイルの指示ファイル）
- スキルはClaudeが仕事の前に読む指示ファイル。色・フォント・アニメーション・音など、自分の編集スタイルを細かく書いたもの。投稿者のスキルは「YouTube-Edit」という名前で約1,400行、36のルールがある
- Claude Codeがこのスキル自体を作ってくれた。Claudeがツール群を動かし、投稿者が「良い見た目とは何か」を教える、という分担

## セットアップ手順
1. Claudeのデスクトップアプリをダウンロードしてアカウントを作る（Googleまたはユーザー名・パスワード）
2. 有料プランにする（投稿者はMaxプラン月200ドルだが、最初は20ドルプランで十分としている）
3. Claude Codeタブを開く。ローカル（自分のパソコンを使う）に設定し、作業フォルダを決める
4. 権限を自動（auto）にして、毎回確認を求められないようにする。モデルは最新のものにし、インターネット閲覧をオンにする（設定から）
5. Claudeに「Hyperframes、FFmpeg、Tella、Epidemic Soundsを使った動画編集システムを作って。セットアップをステップごとに教えて」と頼むと、Claudeが自分で設定を進める
6. コネクタ（左メニューのCustomize→Connectors）でTellaとEpidemic Soundを接続する（ログイン画面が出る）。HyperFramesが見つからなければ検索してリポジトリから入れるか、コネクタ内から追加する
7. 全部つないだら、スキルとして保存させる。新しいスレッドで最初のテストをする

## スタイルを教える方法（育て方）
- 最初は小さいクリップ（フック部分）から始め、最初の編集にタイムスタンプ付きの具体的なフィードバックを返す（「22秒のところをこうして」など）
- 10日目にはフック1本に音だけを試し、8〜10種類の効果音を試して好みを見つけた。音が多すぎるときは「この音を小さくして」「この音は完全に消して」と指示する
- **フィードバックしたら、必ず「学んだことをスキルに保存して」と伝える**。次の編集から同じミスをしなくなる。新しい発見（アニメーション等）があればスキルに追加し、使うたびに微調整する
- 効果音の例：何かが表示されるときの「ポップ」、クリック時の「カチッ」という音。表示の大きさや色の好みも同じ方法で教える

## 実際の使い方（デモ）
- フックの素材を渡して「私のYouTube編集スキルでこのフックを編集して」と頼む。追加の指示も付けられる（「ズームと言うときはズームを見せて」「効果音と言うときは効果音を入れて」「印象的なアニメーションを3つ見せて」など）
- 処理には10〜20分かかる。V1（初版）ができたら、タイムスタンプ付きで修正指示を出す（「サスペンスの音を全体に入れて」など）。最後に「今やったことから学んで、スキルに追加して」と伝える
- 今は素材を丸ごと渡すだけ。Tellaで録画した場合はファイル名を伝えるだけで、Claudeが直接アクセスする。人間は監督（ディレクター）、Claudeが編集者、という分担
