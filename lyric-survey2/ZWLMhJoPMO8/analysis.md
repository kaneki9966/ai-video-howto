# リリックビデオ スタイル分析：「ここで生きてる」（探偵はもう、死んでいる。）

## 基本情報
- タイトル：「ここで生きてる」リリックビデオ
- 投稿者：KADOKAWAanime
- 動画ID：ZWLMhJoPMO8 / 長さ：約1:34（実測94.0秒）
- 備考：本編はアニメ本編映像のモンタージュ＋歌詞重ね。末尾90sは Season2 新ビジュアル解禁の告知カードで、歌詞パートではない。
- 分析方法：720p以下でダウンロードし、5s / 18s / 35s / 52s / 68s / 82s / 90s の7枚を抽出・目視。文字の動きは静止画の差分からの推定と明記する。

## モチーフ / 舞台装置
- 舞台はアニメ本編の名場面そのもの：飛行機内／室内の白髪ヒロイン（シエスタ）のクローズアップ、テーブルに手を置くカット、空港ロビーで振り返る主人公、青空バックの笑顔など。
- 抽象背景ではなく「ファンが既に知っている場面」を再編集し、歌詞をその上に詩のタイポグラフィとして重ねる記念映像型。18sのように歌詞なしで場面だけ見せる間も作る。
- 画面は白い余白（レターボックス的な白フチ）に囲まれる場面が多く、アルバム／写真集のような清潔感がある。

## フォントと文字演出
- 書体：細い明朝系を基本に、文字の一部だけマゼンタ（濃ピンク）で染める「部分着色」が最大の特徴。例：35s「いつもと」、52s「あの世界で」、68s「約束をするよ」はいずれも黒字の中にピンクのストローク／はらいが混ざる。
- 縦横の切替が激しい：横書き固定ではなく、52sは右端に縦書き「あの世界で」＋左下に横書き「見つ」、68sは左側に縦書きで大きく「約束をするよ」と、歌詞を画面の空きスペースに合わせて縦横・大小を変えて配置する。
- サイズ強弱：35s下部の「いつもと」は画面幅いっぱいに巨大化し、はみ出し気味に置く一方、5s冒頭は左下にごく小さな白抜き風の1行（字幕サイズ）から始める。同じ曲の中で字幕サイズ→ポスターサイズまで振る。
- 配置：中央固定を避け、人物の顔を避けた四隅・端に逃がすレイアウト。文字がキャラクターと競合せず、両方が主役になる。
- 出現／消失（推定）：文字の一部がピンクに滲む見え方から、1文字ずつ／フレーズ単位でフェード＋色が後から付く演出と推定される。35s右上の文字は輪郭線だけの白抜き状態で写っており、出現途中のマスク／線画状態を捉えた可能性が高い（推定）。

## 色設計
- ベースはアニメ映像の明るい自然色（肌色、青空、空港の緑がかった床）。そこに歌詞のアクセントとしてマゼンタを一点投入する統一ルール。
- 文字のピンクは告知カード（90s）の「探偵はもう、死んでいる。Season2」ロゴ色とも一致し、作品全体のキーカラーとして機能している。
- 白フチ＋明るい映像＋黒明朝＋ピンク差し色、で「暗くしないリリックビデオ」の好例。

## 画面の変化のさせ方
- 背景素材の差し替えではなく、本編カットの切り替えで進む。カットが変わるたびに歌詞の置き場所・縦横・サイズを設計し直すので、同じ歌詞表示でも毎回画面の顔が違う。
- 82sのように歌詞を消して笑顔のクローズアップだけを抜く「文字なしの溜め」を挟み、次の歌詞を際立たせる。

## サビ・フックの落差の作り方
- 落差は「文字の大きさと密度」で作る：序盤＝小さな字幕的歌詞（5s）→ 中盤＝端に縦書きで散らす（52s）→ 決め所＝顔の横に大きな縦書き「約束をするよ」（68s）や画面幅いっぱいの「いつもと」（35s）。
- 感情のピークでは色も濃くなる：ピンクの面積が増え、文字が黒一色から黒×ピンクの二色になることで視覚的な熱量が上がる（静止画比較からの推定含む）。
- 最後は歌詞を止め、青空＋笑顔（82s）→ ピンク空の告知カード（90s）へ送る二段構えで、曲の余韻を告知に接続する。

## 真似したい点（1〜2個）
1. **明朝の一部だけキーカラーで染める部分着色**：全文字を色付けせず、はらいや一画だけピンクにするだけで高級感と作品色が出る。Remotionでも文字をSVGパス／span分割すれば再現可能。
2. **空きスペースに合わせて縦横・サイズを変える自由レイアウト**：中央下の字幕に固定せず、カットごとに「顔の横に縦書き大」「下部に横書き特大」と置き場所を設計し直す。場面写真＋歌詞の自作リリックビデオにそのまま使える。
